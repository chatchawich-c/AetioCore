# SEMFlow & SEMFlow-DL (`v0.1.0`)

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://chatchawich-c.github.io/SEMFlow/)
[![License](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-green)](LICENSE-APACHE)

Unified Pure-Rust ecosystem for **Scalable Structural Equation Modeling (`SEMFlow`)** and **Edge-Level White-Box Causal Deep Learning (`SEMFlow-DL`)** with zero-copy Python and R bindings.

## Installation

```bash
pip install semflow semflow-dl
```

```r
install.packages("semflow", repos = c("https://chatchawich-c.r-universe.dev", "https://cloud.r-project.org"))
```
