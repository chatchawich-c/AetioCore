# AetioCore-SEM & AetioCore-DL (`v0.1.6`)

**AetioCore-SEM** provides high-performance Covariance-Based SEM (CB-SEM with ML/GLS/ULS and Pattern-Grouped FIML), Variance-Based PLS/PLSc, and Systemic Risk Propagation in Pure Rust with Python and R bindings.

**AetioCore-DL** extends the `lavaan`-compatible DSL with Monotonic I-Spline edge operators, Pearl's counterfactual `do(X)` mediation, spatial CSR coupling, and distribution-free Split-Conformal prediction.
